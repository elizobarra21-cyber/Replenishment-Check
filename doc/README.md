# Store Replenishment Docs

Эта папка - рабочая документация проекта. Ее задача: дать новому разработчику или AI-агенту быстрый и точный контекст без раскопок в переписке.

## Что читать первым

1. [PRODUCT_CONTEXT.md](./PRODUCT_CONTEXT.md) - что за продукт мы делаем и для кого.
2. [DEVELOPMENT_PLAN.md](./DEVELOPMENT_PLAN.md) - фазы разработки и критерии успеха.
3. [AGENT_NOTES.md](./AGENT_NOTES.md) - инструкции для Codex, Claude и других AI-агентов.
4. [CHANGELOG.md](./CHANGELOG.md) - что менялось, когда и почему.
5. [GITHUB_PUBLISHING.md](./GITHUB_PUBLISHING.md) - подготовка репозитория к публикации.

## Правило сопровождения

После каждой содержательной итерации нужно обновлять [CHANGELOG.md](./CHANGELOG.md). Если меняется продуктовая логика, API-контракт, модель данных или процесс разработки, нужно также обновить соответствующий документ в этой папке.
