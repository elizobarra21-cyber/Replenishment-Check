# Языки интерфейса

Языки: английский (`en`), русский (`ru`), иврит (`he`), арабский (`ar`). Иврит и арабский - справа налево (RTL).

## Как устроено

- `lib/i18n/core.ts` - список языков, `translate`, `msg`, без React (работает и на сервере).
- `lib/i18n/react.tsx` - `I18nProvider` (в `app/layout.tsx`) и хуки `useI18n()` / `useT()`.
- `app/components/language-switcher.tsx` - переключатель на главном экране и на экране входа.
- Выбор языка хранится в cookie `lang`. Пока выбора нет, язык берется из языка телефона (`Accept-Language`), иначе английский. Сервер ставит `<html lang dir>` сразу, без мигания.
- Ключ перевода - английский текст: `t("Add to list")`. Нет перевода - показывается английский.
- Подстановки: `t("Remove {name}", { name })`. Если вместо текста нужен React-узел (жирное имя и т. п.) - `rich("You belong to {store}.", { store: <b>{name}</b> })`.
- Множественное число: ключ с `{n}`, `t("{n} people", { n })`. Формы пишутся объектом в словаре: `{ one, two, few, many, other }` (по `Intl.PluralRules` языка). Для английского формы лежат в `lib/i18n/dict/*.en.ts`.
- Тексты в таблицах и на сервере помечаются `msg("...")` там, где определены, а переводятся при показе: `t(label)`. Ошибки API (`{ error: "..." }`) экран показывает через `t(json.error)`.
- PDF-отчет: русский или английский (шрифт PDF не умеет иврит и арабскую вязь), язык берется из cookie.

## Словари

`lib/i18n/dict/<часть>.<язык>.ts`, части: `common` (ошибки сервера, `lib/`), `main` (`app/page.tsx`), `settings` (`app/settings`, `app/join`, `app/components`). Запись строго в виде `  "English text": "перевод",` (два пробела, двойные кавычки) - так их читает проверка.

```bash
node scripts/i18n-check.mjs            # чего не хватает в ru/he/ar
node scripts/i18n-check.mjs --keys     # все ключи
node scripts/i18n-check.mjs --only app/settings
```

Новый текст в интерфейсе - сразу через `t()` и сразу перевод во все три словаря.

## Что не переводится

Номера товаров, коды, размеры (`S`, `M`, `38`, `29/32`), `COS`, имена людей и филиалов, заметки сотрудников, адреса и email.

## RTL

- Для отступов и сторон - логические классы Tailwind: `ms-/me-`, `ps-/pe-`, `start-/end-`, `text-start/text-end`, `border-s/border-e`, `rounded-s/rounded-e`. Не `ml-/mr-/pl-/pr-/left-/right-/text-left/text-right`, кроме центрирования (`left-1/2 -translate-x-1/2`) и мест, где сторона не зависит от языка.
- Стрелки-направления (`←`, `→`, `›`) - в `<span className="inline-block rtl:rotate-180">`.
- Поля для цифр и кодов можно держать `dir="ltr"`, чтобы код читался как на этикетке.

Стиль: короткие кнопки, как в приложениях на телефоне. Русский - без обращения на «вы» с родом («Вы вошли» -> «Вход выполнен»). Иврит - инфинитив или нейтральные формы («להוסיף לרשימה»), без мужского/женского императива. Арабский - обычный нейтральный стиль интерфейсов (масдар: «إضافة إلى القائمة»).
