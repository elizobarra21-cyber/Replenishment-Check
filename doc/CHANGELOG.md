# Changelog

Формат: новая запись сверху. После каждой итерации фиксировать, что изменилось и почему.

## 2026-06-07 - Документационная база и GitHub preparation

Что изменилось:

- Добавлена папка `doc/` с продуктовым контекстом, планом разработки, заметками для AI-агентов, changelog и GitHub checklist.
- `AGENTS.md` будет указывать будущим агентам читать документацию перед изменениями.
- `README.md` будет заменен с шаблонного Next.js README на проектное описание.
- Добавляется `.env.example`.
- `.gitignore` будет дополнен локальными SQLite DB и SQLite sidecar-файлами.

Почему:

- Нужно, чтобы нового разработчика или AI-агента можно было подключить без восстановления контекста из переписки.
- Нужно подготовить проект к безопасной публикации на GitHub без секретов и локальной базы данных.

## 2026-06-07 - Уточнение suggested sizes

Что изменилось:

- `Suggested sizes` теперь считается от обязательного набора зала `XS S M L XL`.
- Размеры можно выбирать до завершения OCR.
- Один размер можно выбрать несколько раз.
- Нажатие на выбранный размер удаляет одну штуку.
- Расчет на фронте и в `/api/scan` приведен к одному правилу.

Почему:

- Product requirement: suggested sizes - это недостающие размеры из понимания, что в зале должен быть полный набор `XS S M L XL`.

## 2026-06-07 - Парсинг 17-значного кода этикетки

Что изменилось:

- Парсер этикетки переведен на 17-значный код над баркодом.
- Поддержан код слитно и с пробелами.
- Разбор: первые 7 цифр article, следующие 3 color, следующие 2 ignore, следующая 1 season, последние 4 storage.
- `Last parsed code` отображается с пробелами.
- Старый короткий формат больше не считается целевым.

Почему:

- Реальная этикетка содержит длинный код над баркодом, а не старую короткую структуру.

## 2026-05-31 - Hall/Warehouse MVP alignment

Что изменилось:

- Hall mode приведен к порядку блоков: scanner, parsed code, sizes, suggested sizes, add, go warehouse, short list.
- Warehouse mode показывает группировку по отделам, сортировку по article/season/color и детальную карточку.
- Добавлено сохранение `color`, `season`, `storageSection` в `RequestItem`.
- Клик по article открывает сохраненное фото скана, если оно есть.
- Добавлена Prisma migration для полей этикетки.

Почему:

- Нужно было привести приложение к продуктовому ТЗ и сделать данные консистентными между Hall и Warehouse.
